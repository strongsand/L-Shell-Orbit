# Public orbital fixtures

`celestrak-starlink-samples.json` contains five public OMM records retrieved on
2026-09-30 from CelesTrak's Starlink SupGP JSON feed:
https://celestrak.org/NORAD/elements/supplemental/sup-gp.php?FILE=starlink&FORMAT=JSON

`EXPECTED_GENERATION` is added for tests from the reviewed generation asset.
Four examples were absent from the initial five-rule catalog; one unreviewed
payload deliberately remains Unknown. These are public satellite identities and
orbital elements, not captures of a user's terminal, location or network.
CelesTrak data terms apply: https://celestrak.org/usage-policy.php
