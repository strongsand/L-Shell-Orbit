# L-Shell Orbit 0.2.0-beta.3

- AMOLED now offers Original and Black and white. The choice is saved even when switching to another theme.
- The black-and-white variant uses a true-black background and neutral colors across shared app components and widgets.
- Normal speed tests show an identified PoP latency reading from live Dishy gRPC telemetry. Missing, invalid or expired observations remain unavailable; this is not a dedicated speed-test latency measurement.
- Removed the custom haptic feedback setting; Android-controlled feedback remains available.
- Explicit Android SDK 37.0 selection for clean build environments. F-Droid compilation and reproducibility are still pending validation.

Known limitations: a compass detail has insufficient contrast; Android 15 widget-picker previews may retain the previous AMOLED variant; compact history does not label PoP latency. Stronger outage-state and terminal/router identity validation is pending. The maintainer reports physical QA of the debug build; the final signed release still needs smoke testing.
